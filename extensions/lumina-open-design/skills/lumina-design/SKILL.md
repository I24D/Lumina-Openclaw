# Lumina Design

Use the `open-design__*` tools to produce the requested artifact. Do not merely describe what could be designed.

For a new deliverable:

1. Create or select an OpenDesign project with a useful name.
2. Inspect the active project and relevant design systems or skills.
3. Create the artifact and write every required file. Use realistic content, responsive behavior, accessible markup, complete states, and working interactions appropriate to the format.
4. Read the resulting project files to verify that the artifact exists and is coherent.
5. Tell the user the project name or ID, the files created, and that it is available in the Lumina Diseño workspace and OpenDesign Studio.

For an existing deliverable, inspect the project and files before editing. Preserve unrelated work and update only the requested artifact.

Keep the current OpenClaw model. Do not switch providers or models. If the OpenDesign tools are unavailable, report the connection failure clearly instead of claiming that a design was created.
